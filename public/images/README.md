# Images Sesam-Market

Déposez ici les visuels générés (format **.webp**), avec **exactement** les noms
listés dans `docs/PROMPTS_IMAGES.md`. L'application les utilise automatiquement ;
tant qu'un fichier manque, le pictogramme actuel est affiché.

Pour convertir et redimensionner vos PNG générés : placez-les dans
`images-source/<dossier>/` puis lancez `npm run images:optimize`.
